# IDA-Graphy 改造计划

## 一、项目概述

### 1.1 原项目分析

**ida-export** 是一个简洁的IDA反编译导出工具，核心功能：

- 使用 `idalib` 批量处理二进制文件
- 导出反编译代码、字符串、导入/导出表、结构体定义等
- 面向AI分析的文本格式输出

**核心架构：**
```
ida_export.py       # 入口：idalib加载+INP调用
    ↓
INP.py              # 导出逻辑：反编译、字符串、调用图等
    ↓
{binary}-export/    # 文本格式输出目录
```

### 1.2 改造目标

将 **ida-export** 改造为 **ida-graphy**：一个支持多组件共同分析、以Neo4j拓扑驱动的二进制预处理工具。

**核心变化：**
- 从"文本导出"转向"图数据库建模"
- 从"单文件分析"转向"多组件关联分析"
- 增强"数据流分析"能力（READS/WRITES边的详细信息）

---

## 二、图数据模型设计（基于改造.md定义）

### 2.1 节点类型

| 节点类型 | 作用层 | ID生成规则 | 关键属性 |
|---------|--------|-----------|---------|
| `Binary` | 物理层 | SHA256(文件内容) | hash, name, base_addr, arch |
| `Function` | 逻辑层 | MD5(BinaryHash + "_" + RVA) | uid, rva, name, func_type, is_lib |
| `DataSlot` | 数据层 | 结构体：MD5(StructName + "_" + Offset)<br>全局：MD5(BinaryHash + "_GLOBAL_" + RVA) | uid, base_type, offset, name, is_global |
| `String` | 语义层 | MD5(Content) | hash, content, encoding |

### 2.2 边关系

| 边类型 | 路径 | 关键属性 | 用途 |
|--------|------|---------|------|
| `CONTAINS` | Binary→Function/DataSlot/String | - | 物理归属 |
| `CALLS` | Function→Function | type, count | 控制流 |
| `LINKS_TO` | IMPORT→EXPORT | - | 动态链接 |
| `REFERENCES` | Function→String | - | 语义引用 |
| `WRITES` | Function→DataSlot | **op_type, const_val**, loc | 数据流-写 |
| `READS` | Function→DataSlot | **condition, op_type, const_val** | 数据流-读 |

#### 模块2：`dataflow_analyzer.py` - 数据流分析器

**职责：** 使用Hex-Rays ctree visitor分析函数内的读写操作

**核心实现：**

```python
class DataFlowVisitor(ida_hexrays.ctree_visitor_t):
    """基于Hex-Rays ctree的数据流分析器"""
    
    def __init__(self):
        super().__init__(ida_hexrays.CV_FAST)
        self.writes = []  # WRITES边列表
        self.reads = []   # READS边列表
    
    def visit_expr(self, expr):
        # 识别赋值操作 (WRITES)
        if expr.op == ida_hexrays.cot_asg:  # a = b
            target = self._analyze_lvalue(expr.x)
            if target:
                self.writes.append({
                    'slot': target,
                    'op_type': 'ASSIGN',
                    'const_val': self._extract_const(expr.y),
                    'loc': expr.ea
                })
        
        # 识别复合赋值 (WRITES)
        elif expr.op in [ida_hexrays.cot_asgbor, ida_hexrays.cot_asgband]:
            # a |= b, a &= b
            target = self._analyze_lvalue(expr.x)
            op_type = 'OR' if expr.op == ida_hexrays.cot_asgbor else 'AND'
            self.writes.append({
                'slot': target,
                'op_type': op_type,
                'const_val': self._extract_const(expr.y),
                'loc': expr.ea
            })
        
        # 识别读取操作 (READS)
        if self._is_memory_access(expr):
            slot = self._analyze_slot(expr)
            if slot:
                self.reads.append({
                    'slot': slot,
                    'condition': self._is_in_condition(expr),  # 关键：判断是否在条件语句中
                    'op_type': self._get_operation_type(expr),
                    'const_val': None
                })
        
        return 0
    
    def visit_insn(self, insn):
        # 分析if/switch/loop，标记条件读取
        if insn.op in [ida_hexrays.cit_if, ida_hexrays.cit_switch]:
            self.condition_depth += 1
        return 0
    
    def _analyze_lvalue(self, expr):
        """分析左值，识别DataSlot"""
        # 结构体成员访问: obj.member
        if expr.op == ida_hexrays.cot_memref:
            struct_name = self._get_struct_name(expr.x.type)
            offset = expr.m
            return ('struct', struct_name, offset)
        
        # 指针解引用: *ptr
        elif expr.op == ida_hexrays.cot_ptr:
            # 追溯指针来源，判断是否为结构体指针
            pass
        
        # 全局变量访问
        elif expr.op == ida_hexrays.cot_obj:
            if self._is_global_var(expr.obj_ea):
                return ('global', expr.obj_ea)
        
        return None
    
    def _is_in_condition(self, expr):
        """判断表达式是否在条件语句中（if/switch/loop）"""
        # 通过AST父节点追溯
        parent = expr.cexpr.parent
        while parent:
            if isinstance(parent, ida_hexrays.cinsn_t):
                if parent.op in [ida_hexrays.cit_if, ida_hexrays.cit_switch, 
                                ida_hexrays.cit_while, ida_hexrays.cit_for]:
                    return True
            parent = getattr(parent, 'parent', None)
        return False
```

**关键技术点：**

1. **结构体成员识别**（基于IDA SDK文档的 `ida_bytes.is_stroff` / `get_stroff_path`）：
   ```python
   def identify_struct_member(self, ea, op_idx):
       insn = ida_ua.insn_t()
       if ida_ua.decode_insn(insn, ea):
           if ida_bytes.is_stroff(insn.ops[op_idx].type):
               path = ida_bytes.get_stroff_path(insn, op_idx)
               # 获取结构体名和偏移量
               return (struct_name, offset)
   ```

2. **全局变量识别**：
   ```python
   def is_global_var(self, ea):
       seg = ida_segment.getseg(ea)
       if seg and seg.type in [ida_segment.SEG_DATA, ida_segment.SEG_BSS]:
           return True
       return False
   ```

import csv
import os

class CSVExporter:
    def __init__(self, output_dir):
        self.output_dir = output_dir
        os.makedirs(output_dir, exist_ok=True)
    
    def export_all(self, nodes, edges):
        """导出所有节点和边到CSV文件"""
        # 导出节点
        self._export_binary_nodes(nodes['Binary'])
        self._export_function_nodes(nodes['Function'])
        self._export_dataslot_nodes(nodes['DataSlot'])
        self._export_string_nodes(nodes['String'])
        
        # 导出边
        self._export_contains_edges(edges['CONTAINS'])
        self._export_calls_edges(edges['CALLS'])
        self._export_links_to_edges(edges['LINKS_TO'])
        self._export_references_edges(edges['REFERENCES'])
        self._export_writes_edges(edges['WRITES'])
        self._export_reads_edges(edges['READS'])
        
        # 生成Neo4j导入脚本
        self._generate_import_script()
    
    def _export_binary_nodes(self, binaries):
        path = os.path.join(self.output_dir, 'nodes_binary.csv')
        with open(path, 'w', newline='', encoding='utf-8') as f:
            writer = csv.writer(f, escapechar='\\', quoting=csv.QUOTE_MINIMAL)
            # 写入Header（Neo4j导入格式）
            writer.writerow([
                'hash:ID(Binary)',
                'name:string',
                'base_addr:long',
                'arch:string',
                'compile_ts:long',
                ':LABEL'
            ])
            # 写入数据
            for b in binaries:
                writer.writerow([
                    b['hash'],
                    b['name'],
                    b['base_addr'],
                    b['arch'],
                    b.get('compile_ts', 0),
                    'Binary'
                ])
    
    def _export_function_nodes(self, functions):
        path = os.path.join(self.output_dir, 'nodes_function.csv')
        with open(path, 'w', newline='', encoding='utf-8') as f:
            writer = csv.writer(f, escapechar='\\', quoting=csv.QUOTE_MINIMAL)
            writer.writerow([
                'uid:ID(Function)',
                'rva:long',
                'name:string',
                'size:int',
                'is_lib:boolean',
                'func_type:string',
                'signature:string',
                'complexity:int',
                'binary_id:string',
                ':LABEL'
            ])
            for f in functions:
                writer.writerow([
                    f['uid'],
                    f['rva'],
                    f['name'],
                    f.get('size', 0),
                    'true' if f.get('is_lib', False) else 'false',
                    f.get('func_type', 'NORMAL'),
                    f.get('signature', ''),
                    f.get('complexity', 0),
                    f.get('binary_id', ''),
                    'Function'
                ])

                'uid:ID(DataSlot)',
                'base_type:string',
                'offset:int',
                'size:int',
                'name:string',
                'is_global:boolean',
                ':LABEL'
            ])
            for d in dataslots:
                writer.writerow([
                    d['uid'],
                    d['base_type'],
                    d['offset'],
                    d['size'],
                    d['name'],

   def link_import_export(self, all_nodes):

       links_to_edges = []
       
       # 构建EXPORT函数索引
       export_index = {}  # {(dll_name, func_name): func_uid}
       for func in all_nodes['Function']:
           if func['func_type'] == 'EXPORT':
               binary_name = self._get_binary_name(func['binary_id'])
               export_index[(binary_name.lower(), func['name'])] = func['uid']

       for func in all_nodes['Function']:

                   links_to_edges.append({
                       'from': func['uid'],
                       'to': export_index[key],
                       'type': 'LINKS_TO'
                   })
       
       return links_to_edges

## 五、关键技术难点与解决方案

### 5.1 如何准确识别WRITES/READS操作？

**难点：** Hex-Rays ctree较为复杂，需要递归分析表达式树

**解决方案：**
- 使用 `ctree_visitor_t` 模式遍历所有表达式和语句
- 对于WRITES：重点关注 `cot_asg`, `cot_asgbor`, `cot_asgband`, `cot_asgadd` 等赋值操作
- 对于READS：识别 `cot_memref`, `cot_memptr`, `cot_obj` 等访存操作
- 使用 `ida_bytes.is_stroff()` 判断操作数是否为结构体成员

**参考代码：**（基于IDA SDK文档中的示例）
```python
def visit_expr(self, e):
    # 检测赋值操作
    if e.op == ida_hexrays.cot_asg:
        lhs = e.x  # 左值
        rhs = e.y  # 右值
        
        # 分析左值，判断是否为DataSlot
        if lhs.op == ida_hexrays.cot_memref:
            # 结构体成员访问：obj.member
            struct_type = lhs.x.type
            member_offset = lhs.m
            # 生成DataSlot ID
            slot_id = self.id_gen.get_struct_slot_id(struct_type.dstr(), member_offset)
            
            # 提取右值常量
            const_val = None
            if rhs.op == ida_hexrays.cot_num:
                const_val = hex(rhs.numval())
            
            # 创建WRITES边
            self.writes.append({
                'from': self.current_func_id,
                'to': slot_id,
                'op_type': 'ASSIGN',
                'const_val': const_val,
                'loc': e.ea
            })
    
    return 0
```

### 5.2 如何判断读取操作是否在条件语句中？

**难点：** 需要追溯AST父节点，判断当前表达式的上下文

**解决方案：**
- 在visitor中维护 `condition_depth` 计数器
- 当进入 `cit_if/cit_switch/cit_while` 时 depth++，退出时 depth--
- 或者通过 `expr.parent` 属性向上追溯AST树

**参考代码：**
```python
class DataFlowVisitor(ida_hexrays.ctree_visitor_t):
    def __init__(self):
        super().__init__(ida_hexrays.CV_FAST)
        self.condition_depth = 0
    
    def visit_insn(self, i):
        if i.op in [ida_hexrays.cit_if, ida_hexrays.cit_switch]:
            self.condition_depth += 1
            # 遍历条件表达式
            if i.op == ida_hexrays.cit_if:
                i.cif.expr.accept(self)  # 访问if条件
            self.condition_depth -= 1
        return 0
    
    def visit_expr(self, e):
        # 记录读取操作
        if e.op == ida_hexrays.cot_memref:
            self.reads.append({
                'slot': ...,
                'condition': self.condition_depth > 0  # 关键标记
            })
        return 0
```

### 5.3 如何处理嵌套结构体的偏移量计算？

**难点：** 结构体可能有多层嵌套，需要计算扁平化的绝对偏移量

**解决方案：**
- 使用 `tinfo_t.iter_struct()` 递归遍历
- 累加父结构体的偏移量

**参考代码：**
```python
def flatten_struct(self, struct_name, base_offset=0, prefix=''):
    """递归扁平化结构体，返回所有成员的绝对偏移量"""
    ti = ida_typeinf.get_idati()
    tinfo = ida_typeinf.tinfo_t()
    if not ida_typeinf.parse_decls(ti, struct_name, tinfo, 0):
        return []
    
    slots = []
    for udm in tinfo.iter_struct():
        member_offset = base_offset + (udm.offset // 8)  # 位转字节
        member_name = f"{prefix}{udm.name}"
        
        # 如果成员是嵌套结构体，递归处理
        if udm.type.is_struct():
            nested_name = udm.type.dstr()
            slots.extend(self.flatten_struct(nested_name, member_offset, f"{member_name}."))
        else:
            # 基础类型成员，创建DataSlot节点
            slots.append({
                'uid': self.id_gen.get_struct_slot_id(struct_name, member_offset),
                'base_type': struct_name,
                'offset': member_offset,
                'name': member_name,
                'size': udm.type.get_size(),
                'is_global': False
            })
    
    return slots
```

### 5.4 跨二进制关联：如何确保结构体DataSlot的ID一致性？

**关键设计：** DataSlot的ID生成规则**不包含BinaryHash**

**验证方式：**
```python
# 在不同二进制中访问同一个结构体
# 场景：user32.dll 和 app.exe 都访问 RECT 结构体的 left 成员

# user32.dll 中的某个函数
id_gen_user32 = NodeIDGenerator(user32_bin_hash)
slot_id1 = id_gen_user32.get_struct_slot_id("RECT", 0)  # offset=0 表示 left 成员

# app.exe 中的某个函数
id_gen_app = NodeIDGenerator(app_bin_hash)
slot_id2 = id_gen_app.get_struct_slot_id("RECT", 0)

# 验证：slot_id1 == slot_id2 （因为不包含BinaryHash）
assert slot_id1 == slot_id2
```

这样在Neo4j中，两个不同二进制的函数可以WRITES/READS到同一个DataSlot节点，实现跨组件数据流追踪。

## 七、风险与挑战

### 7.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| Hex-Rays反编译失败 | 部分函数无法分析数据流 | 记录失败函数，输出到日志；对汇编层做备用分析 |

| 结构体类型识别复杂 | DataSlot节点生成不完整 | 优先支持显式定义的结构体，后续扩展到隐式推断 |
| CSV文件过大 | 数百MB的CSV文件难以版本管理 | 使用gzip压缩；或分批导出（每批100MB） |

### 7.2 数据一致性风险

| 风险 | 应对措施 |
|------|---------|
| 同名结构体在不同二进制中定义不同 | 在结构体名中加入 size/member_count 哈希后缀以区分 |
| 全局变量命名冲突 | 全局变量ID包含BinaryHash，确保隔离 |
| 跨组件关联时找不到EXPORT函数 | 提供"未解析导入"报告，人工介入标注 |
